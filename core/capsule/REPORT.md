## Етап 1. Перевірка Docker

Виконано команду:

docker version

Результат: Docker успішно встановлений та доступний для роботи.

## Етап 2. Робота з контейнером

Запущено контейнер:

docker run -it --name devbox-bravo ubuntu:24.04 bash

Перевірка PID:

echo $$

Результат:

1

Перелік процесів у контейнері:

ps aux

Кількість процесів у контейнері:

ps aux | wc -l

Результат:

4

Кількість процесів на хості:

ps aux | wc -l

Результат:

25

Спостереження: у контейнері видно значно менше процесів, ніж на хості.

Створено файл level1.sh.

Скрипт створює контейнер vtfk-lab01 на основі ubuntu:24.04, записує VTFK_NONCE у /tmp/vtfk-nonce та виводить кількість процесів у контейнері і на хості.

CONTAINER_PROCS=64
